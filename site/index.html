Text, images and file references, hanging within reach. Clippboard keeps your clipboard history locally, with paper notes, adjustable themes and a keyboard shortcut.

Public alpha 0.5.1. GitHub downloads are available. Microsoft approved the 0.5.1 Store package and publication has started; its catalog page is being verified. GitHub EXEs remain unsigned and can show a Windows SmartScreen warning. Device coverage and Store-installed behavior are still being tested.

On your computer

Encrypted local history. No app account, telemetry or cloud uploads.

On your terms

Pause capture, star notes, set retention from 1–30 days, or clear history.

Open to everyone

Apache 2.0 source, public feedback and transparent development.

Before you try it

What does it remember?

Plain Unicode text, bitmap images and original file locations. File notes require accessible originals; HTML styling and virtual attachments are not preserved.

Which Windows versions?

The initial target is Windows 11 x64. Windows 10 and ARM64 support are not advertised.

How do I share feedback?

Use Help in the app or the repository's bug form. Reports are never sent automatically; review screenshots before sharing them.
