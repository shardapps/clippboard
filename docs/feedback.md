# Feedback without uploading your clipboard

Open **Help** in settings or click the speech-bubble button on the rope. **Report a bug** opens the repository's structured issue form with the app version; **Suggest a feature** opens the feature form; **Discuss an idea** opens GitHub Discussions. The browser is opened only on a click. GitHub may ask you to sign in. Clippboard never submits a report automatically.

**Copy support information** is optional and writes version, Windows build, process architecture and .NET version to your clipboard. The text is shown before you copy it. It excludes history, file paths, username and device identifiers. Selecting this action deliberately replaces your current clipboard; when capture is enabled the support text can become a normal history note.

Use synthetic text, pictures and file names in reports. Review screenshots for personal details. Include reproduction steps, expected/actual behavior, version, and destination app when relevant. Send sensitive findings through [private vulnerability reporting](https://github.com/shardapps/clippboard/security/advisories/new), following [SECURITY.md](../SECURITY.md).

Repository discoverability uses descriptive metadata, relevant topics, a clear README, factual FAQ, screenshots and documented limits. These make the project easier to find and cite; they do not guarantee search ranking or AI recommendations.
