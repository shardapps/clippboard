Text, images and file references, hanging within reach. Clippboard keeps your clipboard history locally, with paper notes, adjustable themes and a keyboard shortcut.

Public beta 0.6.0-beta.5. Available on GitHub with searchable history, snippets, optional OCR, encrypted backups and lower-memory Balanced rendering. GitHub EXEs remain unsigned and can show a SmartScreen warning. Microsoft Store has a separate certification and rollout process and may still deliver 0.5.1. Device coverage and Store-installed beta behavior remain under validation.

On your computer

Encrypted local history. No app account, telemetry or cloud uploads.

On your terms

Pause capture, star notes, set retention from 1–30 days, or clear history.

Open to everyone

Apache 2.0 source, public feedback and transparent development.

Before you try it

What does it remember?

Unicode text, bounded HTML/RTF, bitmap images and original file locations. File notes require accessible originals; virtual attachments are not supported. Previews remain inert and rich formats depend on the destination.

Which Windows versions?

The beta targets Windows 11 x64. Windows 10 and ARM64 support are not advertised.

How do I share feedback?

Use Help in the app or the repository's bug form. Reports are never sent automatically; review screenshots before sharing them.
