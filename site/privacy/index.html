Privacy policy

Your clipboard history stays on your computer. Clippboard has no app account, advertising, telemetry or automatic clipboard uploads.

What the app processes

While running with capture enabled, Clippboard reads supported copied text, bitmap images and original file paths, and records timestamps and starred status so you can find and restore clips. Copied content can include personal information. File contents are not archived; file notes reference the original locations.

The app does not capture keyboard input, take screenshots or retrieve historical Windows clipboard records. Unsupported or oversized items are skipped.

Local storage and protection

Clipboard payloads and history metadata are encrypted on disk using Windows DPAPI for the current Windows user. Content is decrypted in memory when needed for display or restoration. Restoring an item places it on the system clipboard, where other applications may access it. Encryption does not protect against every process running as the same user.

Settings contain configuration, not clipboard content. The app does not send history to us, sell personal information, or include an app network service or automatic crash uploads.

Retention and deletion

You can set retention from 1–30 days. This limit also applies to starred items. Default capacity limits are 500 entries and 256 MiB of encrypted history. Older unstarred clips may be evicted when capacity is reached; new clips are rejected if starred items leave no room. Expiry is checked at startup, before additions and reads, and periodically while running.

Delete a note or use Clear history to remove stored entries, including stars. Clear history inside the app before uninstalling if you want it removed. Deletion does not clear the system clipboard, delete referenced original files, remove independent backups, or guarantee forensic erasure.

Your controls and sensitive content

You can pause capture, choose supported capture types, adjust storage limits and delete history. The app respects supported clipboard exclusion markers, but cannot reliably identify all secrets. Pause before copying passwords or other private content you do not want recorded.

Support and feedback

Feedback and project links open GitHub only when you choose them. Clipboard history is not automatically attached. Any information you choose to post is handled by GitHub; public issues are visible to others. Please do not post clipboard contents, passwords, private file paths or identity documents.

For privacy questions, contact the project through Clippboard support. You can read the technical storage documentation and inspect the source code.

This website

This policy website is hosted by GitHub Pages. We add no analytics, scripts, forms or cookies. GitHub may process ordinary web-request information, such as IP addresses and browser details, under the GitHub Privacy Statement. Visiting this site does not send your clipboard history.

Policy changes

Updates will appear on this page with a revised effective date. Material changes to the app's handling of clipboard information will be documented alongside the release.
